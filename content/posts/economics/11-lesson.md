① 核心结论

2008年全球金融危机不能用一个单一原因解释。

最常见的几个“单因果版本”都不够：

“都是因为美联储利率太低。”

“都是因为华尔街贪婪。”

“都是因为中国买了太多美债。”

“都是因为穷人借了不该借的房贷。”

这些因素中有的确实重要，但真正的危机是一个系统：

全球储蓄和资本流入
→ 美国长期融资条件宽松
→ 房地产需求与房价上升
→ 抵押贷款快速扩张
→ 证券化把贷款转成可交易资产
→ 银行、投行、影子银行加杠杆持有这些资产
→ 评级和风险模型低估相关性
→ 房价停止上涨
→ 次贷违约上升
→ MBS/CDO价格下跌
→ 金融机构资产负债表恶化
→ 融资方要求追加抵押品
→ 被迫卖资产
→ 价格进一步下跌
→ 信用市场冻结
→ Lehman倒闭
→ 全球美元融资体系发生挤兑

最重要的结论是：

房地产下跌本身并不足以制造“全球金融危机”。

真正把一次房地产泡沫破裂变成系统性灾难的，是：

高杠杆 + 短期融资 + 复杂证券化 + 风险高度相关 + 金融机构彼此连接。

这也是我们第一次真正进入现代“资产负债表宏观经济学”。

一、2001年以后为什么全球资金越来越多地流向美国？

先从全球失衡讲起。

中国加入WTO以后，全球制造业分工进一步深化。中国、东亚部分经济体、德国、日本以及后来受益于高油价的石油出口国，出现较大的经常账户顺差。

经常账户可以粗略写成：

CA = S - I

如果一个国家：

S > I

它就有净储蓄流向国外。

而世界整体必须满足：

一国顺差 = 另一国逆差

美国则长期存在：

进口 > 出口

即经常账户赤字。

这意味着另一面必然是：

资本流入美国。

所以不能把美国贸易逆差只理解为：

“美国买太多外国商品。”

它同时意味着：

“外国在净购买美国资产。”

这些资产包括：

- Treasury；
- Agency债券；
- 公司债；
- 股票；
- 银行资产；
- 结构化金融产品。

于是形成一个重要循环：

美国进口商品
→ 美元流向顺差国
→ 顺差国把部分美元投资回美国
→ 美国资产需求增加
→ 美国融资条件受到支持
→ 美国继续能够维持较高消费和投资

这就是2000年代所谓 Global Imbalances 的核心之一。

Ben Bernanke 当时提出著名的：

Global Saving Glut

“全球储蓄过剩”假说。

核心不是说：

世界真的出现了一堆“没地方放的钱”。

而是说：

一些新兴市场、石油出口国等的储蓄意愿相对于本国投资机会较高，于是大量资本流向美国等安全资产市场，压低了长期利率和期限溢价。

这个解释有道理，但必须马上加一个限制：

全球储蓄过剩可以解释“为什么融资环境偏宽松”，却不能单独解释“为什么这些钱最终变成了有毒的次贷、CDO和高杠杆”。

后半段是美国以及跨大西洋金融体系自身制造出来的。

二、低利率到底起了多大作用？

互联网泡沫破裂、2001年衰退和“9·11”冲击以后，美联储大幅降息。

低政策利率会通过多个渠道刺激房地产：

短端利率↓
→ 可调利率房贷初期成本↓
→ 房屋月供下降
→ 购房需求↑

同时：

债券收益率较低
→ 投资者寻找更高收益
→ Search for Yield
→ 对MBS、CDO等信用产品需求增加

因此低利率确实是泡沫形成的一个重要背景。

但如果简单说：

“Fed把利率降到1%，所以发生2008。”

还是过度简化。

因为即使利率低，也并不必然产生系统性危机。

真正的问题是：

便宜资金进入了一个激励结构严重扭曲的抵押贷款—证券化—影子银行系统。

另外，长期房贷利率不仅由联邦基金利率决定，还受到：

- 全球资本流入；
- 长期国债收益率；
- 通胀预期；
- 期限溢价；
- MBS市场需求

影响。

所以正确说法是：

宽松货币环境 + 全球资本流入，为信贷繁荣提供了“燃料”；

但金融制度决定了这些燃料怎样被使用。

三、从“买房贷款”到MBS/CDO：金融创新是怎样改变激励的？

传统银行模式很简单：

银行发放房贷
→ 把贷款留在自己资产负债表
→ 借款人未来30年慢慢还钱

这种模式叫：

Originate to Hold

“发放并持有”。

银行如果放了一笔烂贷款：

损失最终主要自己承担。

所以银行有动力认真调查：

- 收入；
- 首付；
- 信用；
- 房屋价值。

但证券化改变了结构。

银行或贷款机构可以：

发放1000笔房贷
→ 打包
→ 卖给证券化机构
→ 形成Mortgage-Backed Securities
→ MBS

这样原始贷款机构很快就把贷款卖出去了。

这叫：

Originate to Distribute

“发放并分销”。

它本身不是坏东西。

证券化理论上有很多好处：

- 银行可以释放资产负债表；
- 风险可以分散给更多投资者；
- 全球资本可以进入美国房贷市场；
- 房贷融资成本可以下降。

真正的问题是：

如果发放贷款的人不再承担最终风险，筛选借款人的激励可能下降。

于是出现典型的：

Principal-Agent Problem

委托—代理问题。

抵押贷款经纪人按“成交量”拿佣金。

他最关心的可能变成：

贷款能不能做出来，

而不是：

20年以后借款人能不能还。

这就是典型的激励错配。

同时，信贷标准逐渐恶化：

- 低首付；
- 次级贷款；
- 可调利率贷款；
- 初期低利率 teaser rate；
- 收入核验不足。

需要注意：

不能把危机归咎于“次贷借款人太穷”。

真正的问题是金融体系主动创造、包装、杠杆持有这些风险，并假设全国房价不会同时大幅下降。

四、MBS为什么还要切成“分层”？CDO又是什么？

假设我们有一个100亿元房贷池。

这些贷款未来会产生：

本金 + 利息。

我们可以把现金流分成不同优先级：

Senior tranche
Mezzanine tranche
Equity tranche

如果借款人出现损失：

最先损失的是Equity。

比如最初5%的损失由Equity承担。

再往上才伤到Mezzanine。

最后才是Senior。

所以理论上：

Senior tranche

可以非常安全。

如果100亿元房贷只有3亿元损失，而最下面5亿元已经吸收损失：

Senior仍然完整。

这就是：

Tranching

分层。

这本来也是合理的金融工程。

问题出在：

整个模型高度依赖一个假设：

不同房贷违约之间的相关性不能太高。

如果佛罗里达、加州、内华达等不同地区的房贷违约大体互相独立，那么分散确实有效。

但如果它们背后共享同一个风险因子：

全国房价下跌

那么：

Correlation ↑↑

过去看起来独立的贷款会同时违约。

于是原本认为极安全的Senior tranche也会受损。

CDO则进一步把：

MBS的某些中间层
+
其他信用资产

再次打包，再次分层。

于是金融系统开始出现一种危险的幻觉：

把一堆中等或较差的信用风险重新包装以后，可以制造出大量AAA资产。

但金融工程可以重新分配风险，

不能消灭基础资产的总损失。

如果底层房贷整体恶化：

损失最终一定要由某个人承担。

五、真正的炸药：杠杆和影子银行

这是整场危机最重要的地方。

假设一家金融机构：

资产 = 100

负债 = 97

股东权益 = 3

那么杠杆率：

Assets / Equity = 100 / 3 ≈ 33倍

只需要资产价值下降：

3%

理论上：

股东权益就接近归零。

所以高杠杆意味着：

资产价格的小变化
→ 股东资本的巨大变化

为什么金融机构愿意这么高杠杆？

因为繁荣时期：

资产收益率只要高于融资成本，

杠杆可以极大提高ROE。

例如资产收益率：

5%

融资成本：

3%

净利差：

2%

如果不用杠杆，收益很普通。

但用大量借来的钱购买资产：

ROE可以被显著放大。

问题是：

杠杆同时放大亏损。

更危险的是，大量金融机构并不是靠稳定的长期存款融资，而是依赖：

- Repo；
- ABCP；
- Money Market Funds；
- SIV；
- 批发美元融资。

这些机构具有银行的经济功能：

短期借钱
→ 长期持有贷款和证券

但不一定具有传统商业银行同样的：

- 存款保险；
- 稳定存款基础；
- 资本监管；
- 最后贷款人保护。

这就是：

Shadow Banking System

影子银行体系。

它本质上存在一个古老的银行问题：

短借长投。

正常时期，非常赚钱。

恐慌时期，极其脆弱。

六、为什么房价一跌，整个体系会突然反转？

繁荣期存在一个典型正反馈：

房价↑
→ 抵押品价值↑
→ 银行更愿意贷款
→ 更多人买房
→ 房价进一步↑
→ 违约率看起来很低
→ MBS表现良好
→ 投资者更加相信模型
→ 更多资金进入房贷

于是产生一种危险认知：

“房价长期不会全国一起跌。”

这会导致信贷标准进一步放松。

但当房价在2006年前后见顶并开始下降以后，整个反馈链反向运行。

房价↓
→ 房屋净值下降
→ 高杠杆家庭更容易陷入负资产
→ 次贷违约率↑
→ MBS/CDO预期损失↑
→ 证券价格↓
→ 金融机构资产价值↓
→ 杠杆率被动上升
→ 债权人要求更多抵押品
→ 金融机构被迫出售资产
→ 证券价格进一步↓
→ 更多机构资本不足

这里重新出现我们在大萧条学过的：

Fisher Debt Deflation

和现代版本：

Financial Accelerator

金融加速器。

一个本来可能只是：

房价下降20%

的问题，因为金融机构资产负债表高度杠杆化，变成：

信用体系整体收缩。

资产价格和信用之间形成：

价格↓
→ 净资产↓
→ 融资能力↓
→ 被迫卖出
→ 价格进一步↓

这就是为什么资产负债表是理解金融危机的核心。

七、2007—2008：为什么最终演变成“金融挤兑”？

2007年以后，市场越来越不知道：

哪家金融机构到底持有多少有毒资产？

于是问题从：

“某些房贷会亏多少？”

升级成：

“我还能不能相信我的交易对手？”

金融系统高度依赖信用。

银行A借钱给银行B，是因为相信：

B明天还能还钱。

一旦这种信任消失：

Interbank Lending ↓

Repo融资方要求：

更高haircut

例如原来100美元证券可以借：

98美元

现在可能只能借：

80美元。

于是机构突然必须自己补：

18美元现金。

如果拿不出来：

只能卖资产。

这就是：

Run

挤兑。

只不过不像1930年代储户排队取现金。

2008年的挤兑大量发生在：

Repo、批发融资和货币市场

里面。

形式更现代，

经济本质却和银行挤兑非常接近。

2008年9月Lehman Brothers倒闭成为关键断点。

市场开始重新评估：

政府究竟会不会救下一家？

于是风险偏好骤降。

随后AIG、货币市场基金、商业票据市场等都受到冲击。

企业甚至开始担心：

日常短期融资还能不能续上。

所以危机开始从：

华尔街资产价格

传播到：

普通企业工资、库存、投资和就业。

八、为什么2008最终成为“全球美元危机”？

这也是很多简单叙事忽略的一点。

2008并不是只有美国银行买了美国房贷。

全球金融体系已经高度美元化。

尤其很多欧洲银行：

资产端持有大量美元资产

但负债端并没有足够稳定的美元存款。

它们需要通过：

- 美国货币市场；
- FX Swap；
- 批发融资

持续获得美元。

平时没有问题。

危机时：

美元融资突然收缩。

于是全球金融机构同时抢美元。

因此2008不仅是：

美国房地产危机

而是：

Global Dollar Funding Crisis

全球美元融资危机。

这揭示了1971以后美元体系真正重要的一面：

美元不仅是贸易结算货币，

更是全球金融机构的负债和融资货币。

所以当美元融资市场冻结：

冲击会迅速跨国传播。

这也是后来Fed为什么必须向其他主要央行提供美元Swap Lines的重要原因。

九、“中国储蓄导致2008”到底哪里对，哪里错？

现在可以做一个严格判断。

有一定道理的部分是：

中国和其他顺差经济体的高储蓄、外汇储备积累以及全球安全资产需求，确实是2000年代美国长期利率偏低和全球融资条件宽松的背景因素之一。

但错误的强版本是：

“中国买美债直接制造了美国次贷危机。”

因为从：

外国购买美国安全资产

到：

美国金融机构制造大量高风险房贷、错误评级CDO、建立高杠杆影子银行体系

中间存在大量制度环节。

可以把因果分成三层：

第一层：宏观环境

全球储蓄
+
资本流入
+
低利率

提供便宜资金。

第二层：金融制度

证券化
+
评级
+
影子银行
+
监管套利
+
短期融资

决定风险怎样积累。

第三层：微观激励

贷款经纪人
+
银行
+
评级机构
+
资产经理
+
金融机构管理层

都有自己的激励问题。

真正的危机来自三层同时作用。

所以如果只拿一个“中国因素”解释2008，会漏掉最关键的金融机制。

十、不同理论怎样解释2008？

这次危机非常适合把我们之前学的理论重新拼起来。

Keynes / Minsky视角：

繁荣会改变风险偏好。

长期稳定：

→ 人们越来越相信风险低
→ 杠杆增加
→ 融资结构越来越脆弱
→ 最终小冲击也能制造大危机

这就是常被概括成的：

Stability is Destabilizing

“稳定本身会孕育不稳定”。

Fisher视角：

债务通缩和被迫去杠杆：

资产价格↓
→ 净资产↓
→ 实际债务压力↑
→ 被迫卖出
→ 价格进一步↓

Monetarist视角：

会特别关注危机后货币、银行信用和支付体系的崩溃风险，以及央行是否提供足够流动性。

New Keynesian / Financial Frictions：

现代宏观会把：

Borrower Net Worth
Collateral
Credit Spread

直接放进模型。

当借款人净资产下降：

外部融资溢价↑

于是：

投资↓
就业↓
产出↓

这就是金融加速器。

Austrian视角：

会强调此前长期廉价信用造成房地产和资本错配。

这个视角对信贷繁荣有启发，但“危机时应主要让体系自然清算”的强政策版本并不是2008以后主流政策结论。

政治经济学视角：

则会继续问：

为什么利润由金融机构私人获得，

但系统崩溃以后损失却需要公共部门介入？

这会带出：

Too Big to Fail
Moral Hazard
监管俘获
金融权力

等问题。

十一、这场危机给投资者留下什么？

第一，低波动不等于低风险。

危机前几年宏观波动很低、违约率很低。

但这反而鼓励：

杠杆↑

所以：

观察到的波动率下降

可能意味着：

风险消失了，

也可能意味着：

风险正在通过杠杆被积累。

第二，资产价格真正危险的组合不是“贵”，而是：

贵 + 高杠杆 + 短期融资 + 拥挤持仓

如果一项资产只是估值高：

可以缓慢回调。

但如果整个体系用短期债务高杠杆持有：

价格稍跌

就会触发：

Margin Call
Forced Selling
Liquidation

于是价格形成非线性下跌。

第三，要盯资产负债表，不只盯利润表。

一家金融机构季度利润很好，

并不说明它安全。

你还要看：

资产是什么？
负债是什么？
久期是否错配？
资金来源是否稳定？
杠杆多高？
抵押品是什么？
如果市场关闭三个月，它还能不能活？

第四，市场交易的是“谁被迫买、谁被迫卖”。

2008后期很多资产价格已经不是正常DCF定价。

而是：

谁需要现金？

谁收到Margin Call？

谁必须降杠杆？

这就是为什么危机时期：

Liquidity

和：

Balance Sheet Capacity

经常比普通估值模型更重要。

本课真正需要留下的四条框架

1. 全球失衡是危机背景，不是充分原因。

资本流入和低利率提供燃料；

金融结构决定燃料是否变成火灾。

2. 证券化不会自动消灭风险。

风险可以：

转移
重新包装
重新分层

但底层经济损失不会凭空消失。

3. 高杠杆 + 短期融资是系统性危机的核心。

资产只跌一点，
股东资本却可能归零；

融资一停，
长期资产就可能被迫火售。

4. 现代金融危机本质上是资产负债表反馈。

资产价格↓
→ 净资产↓
→ 信贷↓
→ 被迫卖出
→ 资产价格进一步↓

这是我们以后分析任何信用周期都应该先画的第一条链。

时间线推进到2008

现在我们已经走到：

2001中国加入WTO
→ 全球价值链继续深化
→ 顺差国储蓄与外汇储备增加
→ 资本流向美国
→ 全球低利率 / Search for Yield
→ 美国房地产繁荣
→ 次贷扩张
→ MBS / CDO证券化
→ 影子银行扩大
→ 金融杠杆上升
→ 2006房价见顶
→ 2007信用裂缝
→ 2008 Bear Stearns
→ Lehman Brothers
→ 全球金融挤兑
→ 世界经济急剧衰退

这意味着我们已经走到了现代投资世界真正的起点。
