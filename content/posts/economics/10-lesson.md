① 核心结论

1980—2001 不是简单的“政府退出、市场接管”。更准确地说，这是战后制度组合发生了一次重大再平衡：

价格稳定、市场竞争、资本流动和股东回报的重要性上升；工会、资本管制、国有企业和部分行业监管的重要性下降。

与此同时，技术革命和地缘政治变化把全球经济重新连接起来：

Volcker压低通胀
→ Reagan / Thatcher改革
→ 金融市场扩张与资本流动自由化
→ 苏联解体与更多国家进入世界市场
→ 集装箱、通信、计算机降低跨国协调成本
→ 全球价值链形成
→ 东亚工业化、中国改革开放
→ 互联网革命
→ 2001年中国加入WTO

这套体系显著提高了全球生产效率，也使数亿人口进入现代工业体系；但收益并没有均匀分配。资本、技术人才和全球消费者获得了巨大收益，一些发达国家的低技能制造业劳动者和地区则承受了长期调整成本。

所以这一时期最重要的政治经济学结论是：

总蛋糕变大，不代表每个人分到的蛋糕都变大。

一、为什么1980年代成为制度转折点？

上一课讲到，1970年代的滞胀严重打击了战后政策信心。

战后体系大致强调：

- 充分就业；
- 强工会；
- 高度累进税制；
- 大量行业监管；
- 国企和公共服务；
- 资本流动限制；
- Keynesian需求管理。

到1970年代末，批评者认为这套体系出现了几个问题：

- 通胀失控；
- 生产率增速下降；
- 部分国企效率低；
- 工会在一些行业拥有过强市场力量；
- 高税率可能削弱投资激励；
- 管制保护了既有企业，降低竞争。

于是 Reagan 和 Thatcher 并不是凭空出现，而是对1970年代危机的一种政治回应。

政策方向逐渐转向：

降低部分边际税率
+
私有化
+
放松行业管制
+
削弱部分工会力量
+
鼓励金融创新
+
扩大国际资本流动
+
更强调央行控制通胀

这套政策后来经常被统称为“新自由主义”。

但这个词必须谨慎使用。

它不是一个精确的单一经济模型，也不是说政府从此消失。实际上国家仍然：

- 征税；
- 发债；
- 监管银行；
- 提供福利；
- 执行产权；
- 维护货币；
- 进行国防和产业政策。

所以更准确的说法是：

国家干预的方式发生变化，而不是国家从经济中退出。

二、Volcker之后为什么金融市场开始越来越重要？

Volcker打下通胀以后，美国长期通胀预期下降。

如果名义债券收益率可以粗略写成：

i ≈ r + πᵉ + risk premium

当预期通胀 πᵉ 下行时，长期名义利率也获得下降空间。

利率下降会产生非常深远的资产价格影响。

对于一项未来现金流：

PV = Σ CFₜ / (1+r)ᵗ

如果折现率 r 下降：

PV↑

所以1980年代以后，长期利率下降、通胀下降和金融创新共同为：

- 债券；
- 股票；
- 房地产；
- 杠杆融资；

创造了更有利的环境。

这也是以后投资必须掌握的基本逻辑：

资产价格不仅取决于现金流，还取决于折现率。

金融自由化则进一步使资本更容易跨行业、跨地区、跨国寻找最高回报。

理论上的好处是：

- 储蓄流向高生产率项目；
- 企业融资成本下降；
- 风险可以更广泛分散；
- 落后国家可以引入外国资本。

但另一面是：

- 杠杆更容易积累；
- 资本流动速度更快；
- 金融危机传播更快；
- 国家货币政策更容易受到全球资本流动约束。

所以：

金融深化既可以提高资源配置效率，也可以提高系统性脆弱性。

这条矛盾以后会在1997亚洲金融危机和2008全球金融危机中再次爆发。

三、第二次全球化为什么能比第一次更深入？

1870—1914第一次全球化已经存在大量贸易和资本流动，但1980年代后的全球化多了一样关键东西：

全球价值链

以前国际贸易更像：

英国生产布，阿根廷生产牛肉，然后互相交换。

现代全球化则变成：

一个产品的不同生产步骤分布在多个国家。

例如一台电子产品可能是：

美国设计
→ 日本设备
→ 韩国存储
→ 台湾芯片制造
→ 东南亚零部件
→ 中国组装
→ 全球销售

这意味着“一个国家生产什么”已经不够精确。

更重要的问题变成：

一个国家控制价值链中的哪一个环节？

跨国分工突然变得可行，核心是协调成本猛烈下降：

- 集装箱化和现代港口降低物流成本；
- 电话、卫星、传真和互联网降低通信成本；
- 计算机让企业能够管理全球库存、订单、供应商、财务和物流。

于是 Smith 的“分工受市场范围限制”，在这里被推到了全球尺度。

四、为什么全球化能让国家总体获益，同时伤害一部分工人？

这里要把 Ricardo 和现代贸易理论连接起来。

Ricardo告诉我们：

各国按照比较优势专业化，可以提高总产出。

但现实世界不仅有“国家”，还有不同生产要素：

- 高技能劳动；
- 低技能劳动；
- 资本；
- 土地。

Heckscher–Ohlin 模型进一步考虑：

国家会倾向出口密集使用本国相对丰富生产要素的商品。

如果一个发展中国家拥有大量相对低成本劳动力：

L_low-skill abundant

它可能在劳动密集型制造业上具有优势。

而资本和高技能劳动丰富的发达国家，会更多专业化于：

- 技术；
- 金融；
- 高端设备；
- 知识产权；
- 高技能服务。

关键来了：Stolper–Samuelson 告诉我们，贸易扩张即使提高国家总体收入，也可能改变不同生产要素的收入。

一个简化直觉是：

进口竞争↑
→ 本国低技能制造业需求↓
→ 这些工人的工资和就业受到压力

与此同时：

资本、高技能劳动、消费者

可能受益。

因此：

“自由贸易提高总体福利”与“部分工人因自由贸易受损”并不矛盾。

这正是政治争论经常忽视的地方。

五、全球化为什么同时改变了资本—劳动关系？

这里可以把 Marx 的问题重新拿回来。

在一个资本受到严格管制的经济里，企业如果和本地工人谈判：

工资要涨，否则罢工。

企业很难说：

那我明天把整个工厂搬到海外。

但当：

- 资本可以跨境；
- 物流便宜；
- 海外劳动力充足；
- 跨国供应链成熟；

企业的 outside option 改善了。

即：

资本退出本地劳动市场的能力↑

这会改变谈判结构：

资本流动性↑
→ 企业外包/迁厂威胁更可信
→ 部分工人的议价能力下降
→ 工资增长与生产率增长可能脱钩

这并不意味着1980年以后所有工资都停滞，也不能把所有收入不平等都归因于全球化。

因为同时还有：

- 自动化；
- 信息技术；
- 教育差异；
- 工会衰退；
- 税收政策；
- “赢家通吃”市场；
- 金融资产上涨。

但全球化确实改变了劳资谈判的外部环境。

六、中国和东亚为什么成为这套体系的最大受益者之一？

这一阶段最重要的世界经济变化之一，就是东亚工业化。

先有：

- 日本；
- 韩国；
- 台湾；
- 香港；
- 新加坡；

后来中国以远大于这些经济体的规模进入全球制造体系。

中国1978年后逐渐：

- 放松计划经济约束；
- 引入市场价格；
- 允许乡镇企业和私营经济发展；
- 建立经济特区；
- 吸引外资；
- 扩大出口；
- 进行大规模基础设施投资；
- 将农村劳动力转移到城市和制造业。

这产生了一种典型的追赶型增长：

农村低生产率劳动
→ 城市工业劳动
→ 资本积累
→ 技术学习
→ 出口扩大
→ 更多投资

中国拥有几个非常重要的条件：

- 巨大劳动力；
- 巨大潜在国内市场；
- 高储蓄率；
- 基础教育水平；
- 国家基础设施能力；
- 海外华人资本和供应链联系；
- 发达经济体提供的巨大外部市场。

因此中国并不是简单靠“工资低”成功。

世界上工资低的国家一直很多。

真正关键的是：

低成本劳动 + 基础设施 + 制造能力 + 资本 + 组织能力 + 全球市场接入

结合起来。

2001年加入WTO则提高了跨国企业对中国未来贸易制度的可预期性：

制度确定性↑
→ FDI↑
→ 供应链迁移
→ 出口制造业扩大

这会成为下一课2001—2008全球失衡的重要起点。

七、互联网革命为什么既是真革命，又造成了泡沫？

1990年代后半期，美国出现互联网和计算机投资浪潮。

这与1920年代的电气化有一个共同特征：

技术革命是真的，但资产价格仍然可以形成泡沫。

互联网确实最终改变了：

- 商业；
- 广告；
- 通信；
- 零售；
- 媒体；
- 软件；
- 金融。

今天的 Amazon、Google 等商业模式证明，互联网叙事本身没有错。

但市场在1990年代末把大量公司按照极其乐观的未来现金流估值。

如果：

P = Σ E(CFₜ) / (1+r)ᵗ

那么只要市场同时高估：

未来现金流 E(CFₜ)

并低估：

风险

价格就可以远远超过最终合理价值。

于是出现 Dot-com Bubble。

2000年前后泡沫破裂，大量互联网公司消失。

但互联网本身继续改变世界。

这留下了一个对AI投资极其重要的历史经验：

技术革命正确，不等于当前估值正确。

所以完全可以同时成立：

1. AI真的改变世界；
2. AI基础设施需求真的很大；
3. 某些AI公司仍然严重高估。

三者没有逻辑冲突。

八、这一阶段最大的矛盾：效率提升与脆弱性同时积累

1980—2001形成的新体系取得了巨大成果：

全球贸易↑
+
跨国投资↑
+
发展中国家工业化
+
商品价格下降
+
技术扩散
+
企业生产率提高

但它也埋下三类风险。

第一是金融风险：

资本流入
→ 信贷扩张
→ 房地产/资产上涨

但资本也可以突然撤走：

资本外逃
→ 汇率暴跌
→ 外币债务爆炸

1997亚洲金融危机就是典型案例。

第二是地区分配风险。

总体GDP上涨，并不能自动补偿某个工业城市失去的产业。理论上可以：

赢家补偿输家

但现实政治中经常没有充分补偿。

第三是全球失衡。

随着出口国积累外汇储备、美国不断进口并吸收全球储蓄，一个新的循环逐渐形成：

出口国顺差
→ 获得美元
→ 购买美国金融资产
→ 美国融资条件更宽松
→ 美国消费和资产价格受到支持
→ 进口继续扩大

到2000年代，这条链会越来越重要。

本课真正需要留下的四个框架

第一，新自由主义不是政府消失，而是制度权重重新分配。大致从“工会 + 资本管制 + 国企 + 需求管理”，更多转向“竞争 + 私有化 + 金融自由化 + 价格稳定 + 股东价值”。

第二，全球化增加总效率，但存在真实分配效应。

贸易总福利↑ ≠ 所有群体收入↑

第三，技术降低协调成本，创造全球价值链。现代全球化不仅是交换最终产品，而是生产过程本身全球分工。

第四，金融自由化提高效率，也提高危机传播能力。

资本流动↑

既可以把储蓄送到高回报地区，也可以迅速制造信用繁荣和突然停止。

时间线推进到2001

现在我们已经走过：

1979—82 Volcker Shock
→ 1980年代 Reagan / Thatcher
→ 去监管与金融自由化
→ 资本跨境流动扩大
→ 东亚出口工业化
→ 1989—91东欧剧变与苏联解体
→ 全球市场进一步扩大
→ 1990年代信息技术革命
→ 全球价值链深化
→ 1997亚洲金融危机
→ 2000互联网泡沫破裂
→ 2001中国加入WTO

到这里，1990年代很多人一度认为世界已经进入一种相当稳定的组合：

低通胀 + 全球化 + 技术进步 + 独立央行 + 自由贸易 + 金融创新

后来甚至出现所谓 Great Moderation（大缓和）的乐观判断。

但真正危险的东西正在这个体系内部形成。

下一课：2001—2008——中国入世、全球储蓄、低利率与房地产泡沫为什么最终汇成全球金融危机？

下一课我们要第一次完整搭建一场现代金融危机的资产负债表链条：

中国及其他顺差国出口
→ 美元储备积累
→ 美国债券需求
→ 全球储蓄与低利率环境
→ 房地产上涨
→ 抵押贷款扩张

→ 高杠杆
→ 房价下跌
→ 抵押品缩水
→ 金融机构资不抵债

→ 全球美元流动性危机

同时我们会严格区分：

“中国储蓄导致了2008”

这种过度简化说法，

和真正更复杂的：

全球失衡 + 美国监管和金融创新 + 信贷标准恶化 + 杠杆 + 货币环境 + 激励错配

是怎样共同作用的。
