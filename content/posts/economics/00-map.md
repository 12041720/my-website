一、先记住整张地图的核心

1700—2026 年的世界经济史，可以粗略理解成六次大转变：

农业土地经济
→ 工业资本主义
→ 公司化、金融化与帝国主义时代
→ 国家管理的工业资本主义
→ 全球化、金融自由化与美元体系深化
→ 数字资本主义 + 地缘经济竞争 + AI 资本开支时代

而经济思想史几乎一直在追赶这些现实变化：

重商主义
→ Smith / Ricardo 古典经济学
→ Marx
→ 边际革命 / 新古典
→ Keynes
→ Hayek / Monetarism / New Classical
→ New Keynesian / Behavioral / Institutional / Financial Frictions / Heterogeneous-Agent Macro

这里最重要的一点是：

理论不是凭空产生的。重大理论革命，往往发生在旧理论解释不了新的现实之后。

第一时代：1700—1776
商业资本主义、殖民体系与工业革命前夜

此时欧洲大部分人口仍生活在农业社会。土地是最重要的生产资料，粮食产量、人口增长和战争能力密切相关。

但在欧洲沿海国家，已经出现另一套体系：

于是产生了后来被称为重商主义的一整套政策思想：

扶持本国商人；

建立殖民地；

国家直接参与贸易竞争。

它并不是简单的“古人错误地认为贸易顺差越多越好”。

在那个时代，商业、战争、国家财政和帝国扩张本来就是高度绑定的。

与此同时，英国工业革命开始打破人类长期的低增长状态。过去几百年技术进步很容易被人口增长吃掉；工业化以后，持续的人均产出增长第一次成为可能。

这正是 Adam Smith 出现的背景。

1776 年《国富论》真正革命性的地方，不只是“看不见的手”，而是提出：

五、为什么今天的世界会变成现在这个样子？

如果只允许我用 8 个结构性原因解释2026年的世界，我会选这八个。

1. 工业革命让持续经济增长成为可能

因此现代国家最核心的经济政治问题从“如何分有限粮食”，变成：

怎样维持生产率增长，以及增长成果归谁。

2. 资本主义解决了大规模资本动员问题，但同时产生分配问题

股份公司、银行、债券、股票市场让社会可以：

把今天的大量资源投入一个几年甚至几十年以后才产生收入的项目。

铁路、电网、芯片厂、数据中心都依赖这个机制。

但同时就产生：

谁拥有资本？

谁承担风险？

谁拿利润？

工资增长是否跟得上生产率？

这就是政治经济学永远不会消失的原因。

3. 国家并没有随着资本主义发展而退出，反而越来越重要

现代经济依赖：

法律；

货币；

产权；

银行监管；

公共教育；

基础设施；

社会保障；

产业政策；

国防。

所以：

国家 vs 市场

本身就是一个不太好的二元问题。

真正应该问：

国家用什么机制，在什么领域，以什么激励结构干预？

4. 1929证明金融体系可以把普通衰退变成系统危机

因此今天几乎所有现代国家都有：

中央银行；

存款保险；

银行监管；

最后贷款人；

宏观审慎监管。

这不是偶然。

它们都是金融危机留下的制度化记忆。

5. 二战使美国成为世界金融体系中心

美元体系并不仅仅因为“大家相信美元”。

它背后还有：

美国经济规模
+
Treasury市场
+
银行体系
+
全球美元融资
+
法治与金融市场
+
军事与地缘体系
+
网络效应。

所以以后讲“去美元化”，我们不会停留在：

哪国不用美元结算了？

而是会研究：

抵押品、融资、外汇储备、银行负债、跨境债务和衍生品。

6. 1980—2008全球化极大提高效率，也改变了收入分配

全球化可以同时产生：

全球总产出增加

和：

某些地区工人收入受损。

两者完全可以同时成立。

这也是为什么：

“自由贸易总体有利”

不能直接推导出：

“每个人都从自由贸易中获益”。

这会成为我们以后学习 Ricardo 比较优势时最重要的纠偏。

7. 2008以后，资产价格和宏观政策高度绑定

你做股票投资，如果不知道：

无风险利率；

QE；

信用利差；

银行资产负债表；

Treasury；

美元流动性

就很难真正理解现代金融市场。

DCF并没有失效。

相反：

r 的变化就是现代市场很多剧烈波动的来源。

8. 现在技术与地缘政治重新合流

AI、半导体、电网、能源、先进制造已经不再只是企业投资问题。

它们同时是：

国家安全问题

产业政策问题

国际贸易问题

资本市场问题。

所以2020年代正在重新把经济学带回一种非常“古老”的状态：

政治经济学重新变得重要。
六、但不要从这张地图得到一个错误结论

非常容易产生一种历史目的论：

重商主义错了
→ Smith更正确
→ Keynes更正确
→ 现代经济学最终获得真理。

不是这样。

更准确的是：

不同理论抓住了经济系统的不同部分。

例如：

理论传统	特别擅长解释
Smith	分工、竞争、市场协调
Ricardo	分配、比较优势
Marx	资本积累、劳资关系、所有权
Neoclassical	边际选择、价格、资源配置
Keynes	总需求、失业、宏观协调失败
Hayek	分散信息、价格机制
Friedman	货币、通胀、政策规则
New Keynesian	名义刚性与现代货币政策
Behavioral	非理性行为
Institutional	制度与长期发展
Minsky / Financial Frictions	杠杆、信用、金融危机

真正强的分析框架不是选一个人成为信徒，而是：

面对一个问题，知道该调用哪种模型。

这将是我们整个学习过程中最重要的训练。

七、我们的第一阶段课程怎么继续

现在不进入九条主线同时开学。

下一步先完成一个较小的 Phase 1A：现代经济世界是怎么诞生的？

我建议按下面六个问题推进：

工业革命为什么首先发生？
在此之前人类为什么几千年都没有持续提高人均收入？从 Malthusian Trap、能源、技术、制度、殖民、工资和煤炭争论切入。

Adam Smith 到底发现了什么？
不读鸡汤式“看不见的手”，而是研究分工、市场范围、劳动生产率、资本积累、国家和重商主义。

Ricardo、Malthus 与 Marx 为什么都在研究“分配”？
从工资—利润—地租开始，进入19世纪政治经济学真正的问题。

为什么1870年代发生边际革命？
从劳动价值/生产成本问题走向主观价值、边际效用和供需理论，并第一次正式学习微观模型。

第一次全球化为什么在1914—1933之间崩溃？
学习金本位、一战、资本流动、债务、1929和大萧条。

为什么大萧条最终催生 Keynes？
在这里正式进入宏观经济学：GDP、储蓄投资、总需求、失业、货币和利率。

也就是说，我们接下来不是马上学：

“什么叫需求曲线？”

而是先回答一个更基础的问题：

为什么现代经济增长直到大约250年前才出现？

这会自然把我们带入工业革命、Malthus、Smith、资本积累、技术进步和制度，然后我们再从那里正式展开第一课。

这也是我建议我们下一条直接开始的内容：《第一课：工业革命之前，人类为什么富不起来？——从马尔萨斯陷阱到现代经济增长》。
