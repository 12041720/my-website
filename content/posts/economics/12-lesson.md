① 核心结论

2008年以后，全球主要央行面对的是一个和1970年代几乎相反的问题。

1970年代是：

通胀太高
→ 央行必须压低需求

2008年以后则是：

金融体系崩溃
+
私人部门去杠杆
+
失业高
+
需求不足
+
通胀过低甚至有通缩风险

于是政策转向：

政策利率接近0
+
最后贷款人支持
+
银行资本重建
+
QE
+
Forward Guidance

结果是一个非常特殊的2010年代：

低增长
+
低通胀
+
低利率
+
低债券收益率
+
较高资产估值

这里最需要纠正的两个误区是：

第一：

QE = 央行直接“印钱发给居民”

不准确。

第二：

QE没造成1970年代式通胀 = QE完全没有宏观和资产价格影响

也不准确。

更准确的理解是：

QE首先通过银行准备金、债券供给结构、期限溢价、风险溢价、预期和资产组合再平衡作用于金融条件；只有进一步刺激信贷、投资和消费，才会传导到总需求和CPI。

一、2008以后政府和央行到底做了什么？

Lehman倒闭以后，政策目标首先不是“刺激股市”，而是阻止金融体系停止运转。

需要区分几类政策。

第一类：流动性救助

Fed作为最后贷款人，通过贴现窗口、各种紧急流动性工具以及与外国央行的美元Swap Lines，为金融体系提供美元。

逻辑是：

金融机构未必长期资不抵债
但短期融不到钱
→ 央行暂时提供流动性
→ 防止被迫火售资产
→ 防止流动性危机变成偿付能力危机

这里必须区分：

Liquidity Problem

和：

Solvency Problem

流动性问题是：

我资产长期值100，但今天到期要付10现金，我暂时拿不出来。

偿付能力问题则是：

我的资产只值80，却欠100。

央行提供短期贷款能够解决第一种问题，却不能凭空修复第二种。

第二类：银行资本重建和政府担保

这不是Fed单独完成的。

美国财政部通过TARP等机制向金融机构注资，政府还扩大担保和稳定金融体系。

所以以后看到：

“Fed救了所有银行”

必须更准确地拆成：

中央银行提供流动性和货币政策支持；
财政部门承担资本注入和部分信用风险；
监管机构要求银行补资本和修复资产负债表。

第三类：把政策利率降到接近零

传统货币政策是：

经济弱
→ 降低政策利率
→ 银行和市场利率下降
→ 房贷、企业融资、消费信贷成本下降
→ 投资和消费增加

但到2008年底，美国政策利率已经接近零。

这就碰到：

Zero Lower Bound

零利率下限附近的问题。

继续把普通政策利率大幅往下砍已经非常困难。

于是Fed开始大规模资产购买：

Quantitative Easing

即QE。

二、QE到底是怎么“创造钱”的？

这是整个货币金融课程最容易被讲错的地方。

先看中央银行最简资产负债表：

Fed资产：
Treasury
MBS
对银行贷款

Fed负债：
纸币
商业银行准备金
财政部存款等

现在假设Fed从一家商业银行直接买100美元Treasury。

交易前，银行资产中有：

Treasury 100

交易后：

银行：
Treasury -100
Reserves +100

Fed：
Treasury +100
Reserves负债 +100

所以Fed确实“创造”了新的中央银行准备金。

但商业银行的总资产并没有因为这一笔交易直接增加100：

它只是把：

Treasury

换成：

Reserves

也就是：

一种政府/央行负债

换成：

另一种政府/央行负债。

如果Fed从非银行投资者手中购买Treasury，操作会稍微不同。

例如养老金把100美元Treasury卖给Fed。

养老金最终得到：

银行存款 +100

养老金原资产：

Treasury -100

商业银行：

Reserves +100
Deposits负债 +100

Fed：

Treasury +100
Reserves负债 +100

此时银行存款货币也会增加。

但整个私人部门持有的资产结构发生的主要变化仍然是：

长期债券减少
+
流动性更高的存款/准备金增加

所以QE更准确地说是一种：

Asset Swap + Duration/Risk Transformation

资产交换和期限/风险结构改变。

它与财政部门直接给居民发100美元不是一回事。

财政转移支付可以直接提高居民可支配收入和私人部门净金融资产；QE主要改变既有金融资产的构成、价格和收益率。

但注意：

这绝不意味着QE“什么都没做”。

它改变的正是现代金融市场极其重要的变量：

利率
期限溢价
流动性
风险溢价
资产价格
预期

三、为什么“准备金暴涨”没有机械变成银行疯狂放贷？

传统教科书过去经常用一个很简单的Money Multiplier模型：

央行增加100准备金
→ 银行留10
→ 借出90
→ 90又进入银行
→ 再借81
→ ...
→ 最后产生1000存款

这个模型作为非常初步的教学工具有一定直觉，但不能把现代银行实际运作理解成：

银行先获得准备金，然后把准备金借给企业和居民。

现实中，一家银行给企业发放100万贷款时，可以直接记账：

银行资产：
贷款 +100万

银行负债：
企业存款 +100万

也就是说：

Loan creates Deposit

贷款同时创造存款。

商业银行并不会把Fed准备金“转给”普通企业作为企业银行账户里的钱。

准备金主要是银行之间以及银行和中央银行之间使用的结算资产。

银行是否愿意放贷，主要取决于：

有没有信用合格且愿意借钱的客户；
贷款收益是否值得承担风险；
银行资本是否充足；
融资和流动性成本；
监管约束；
经济前景。

2009年以后恰好出现：

家庭去杠杆
+
企业谨慎
+
银行修复资本
+
房地产需求受损
+
贷款风险高

所以即使：

Reserves↑↑

也不意味着：

Bank Lending↑↑

这就是为什么不能看到央行基础货币暴涨，就机械预测：

CPI马上暴涨。

四、QE究竟怎样影响股票、债券和房地产？

QE的传导至少有四条重要路径。

第一：Portfolio Balance Channel

资产组合再平衡。

假设市场原本拥有大量长期Treasury。

Fed买走一部分：

长期安全债券可供私人持有的数量下降。

投资者原来持有的Treasury被换成：

现金/存款/准备金体系中的流动资产。

但投资者并不一定愿意长期持有低收益现金。

于是开始寻找：

公司债
MBS
股票
房地产
其他风险资产

于是：

风险资产需求↑
→ 价格↑
→ 预期收益率/信用利差↓
→ 企业融资条件改善

第二：Term Premium Channel

如果Fed大量买长期债券：

长期债券私人市场供给下降

可能压低：

Term Premium

期限溢价。

所以即使未来短期政策利率预期不变：

10年期收益率也可能下降。

第三：Signaling / Forward Guidance

QE还可以向市场传递：

“央行准备长期维持宽松。”

于是投资者下调：

未来政策利率路径

从而进一步压低中长期收益率。

第四：Market Functioning

危机时期，有些市场不是“价格太低”，而是根本没人愿意做市、报价和融资。

央行购买资产可以恢复市场流动性，降低恐慌性流动性溢价。

Fed官方对资产购买的解释也明确包括降低长期利率、改善金融条件、信号渠道以及危机时改善市场运行。

实际政策上，QE1最终大规模购买了Agency MBS、Agency Debt和长期Treasury；QE2在2010—2011年追加购买6000亿美元长期Treasury；2012年的QE3最初以每月400亿美元购买Agency MBS，随后又加入每月450亿美元长期Treasury购买。

这些政策不是简单“把股市往上推”，但资产价格是重要传导渠道之一。

五、为什么2010年代没有出现1970年代式高通胀？

这个问题必须从总需求而不是“印钱数量”出发。

2008以后存在几股强大的通缩/低通胀力量。

第一，私人部门去杠杆。

危机前：

家庭借钱买房
银行扩张资产负债表
企业投资

危机后：

家庭还债
银行收缩风险
企业谨慎投资

于是：

私人信用创造明显弱于危机前。

第二，经济存在巨大产出缺口。

大量：

失业工人
闲置设备
空置房地产

意味着需求增加首先可能表现为：

产量恢复

而不是：

价格上涨。

第三，财政与货币政策并不是同一种刺激。

QE可以买债券并压低收益率，

但它不会像：

政府直接发1000美元给家庭

那样自动转化成等额居民可支配收入。

所以：

QE的需求刺激通常比简单“印钱发钱”叙事间接得多。

第四，通胀预期仍然较稳定。

Volcker之后建立的央行信誉没有在2008危机中消失。

市场长期并没有普遍相信：

Fed将容忍10%甚至更高通胀。

第五，全球化、技术和劳动市场结构也提供了部分低通胀背景。

全球商品供应链扩大、制造业国际竞争、自动化以及较弱的工资议价压力，都可能限制部分商品和工资价格上涨。

但这里不能过度推论：

“全球化解释了2010年代所有低通胀。”

低通胀是：

弱需求
+
去杠杆
+
较低自然利率
+
稳定预期
+
全球供给结构

等多因素结果。

所以正确结论不是：

QE不会造成通胀。

而是：

QE是否造成多大通胀，取决于它最终让名义支出增长多少，以及经济是否已经接近供给上限。

这会成为理解2020—2022的关键。

六、为什么经济增长一般，股票和房地产却能涨很多？

现在进入投资最重要的问题之一。

资产定价：

P = Σ E(CFₜ)/(1+rₜ)ᵗ

股票上涨可以来自两类东西：

第一：

E(CF)↑

也就是未来企业盈利预期增加。

第二：

r↓

折现率下降。

2010年代两者同时存在，但第二个因素特别重要。

长期利率下降：

→ 无风险收益率下降

信用利差下降：

→ 企业融资成本下降

风险溢价下降：

→ 投资者愿意为同样现金流支付更高价格

于是：

P/E可以上升。

这说明：

GDP增长率并不是股票收益率的简单映射。

一个经济体可能：

实际GDP只增长2%左右

但如果：

企业利润率提高
+
科技巨头利润增长
+
利率下降
+
风险溢价下降

股票仍然可能表现很好。

房地产也类似。

假设房子的年租金是：

3万元

如果投资者要求：

6%收益率

估值约：

3/0.06 = 50万元

如果要求收益率下降到：

3%

同样3万元租金理论估值变成：

3/0.03 = 100万元

真实世界当然没这么简单，但这个例子说明：

长期利率下降本身就可以显著推高久期很长的资产价格。

这就是为什么2010年代很多投资者开始形成：

TINA

There Is No Alternative

“没有替代品”

式叙事：

安全资产收益率太低，
于是被迫承担更多风险。

但这里也埋下一个未来风险：

如果：

r↑

那么过去依靠低折现率支撑的高估值资产会反向承压。

这正是2022年以后成长股估值压缩的理论基础之一。

七、欧债危机为什么暴露了欧元体系的结构问题？

2008危机以后，美国有一个制度优势：

美国财政部发行：

美元债务

而Fed控制：

美元基础货币和美元最后贷款能力。

欧元区却不同。

希腊、意大利、西班牙等国家使用：

欧元

但单个国家不能：

自己发行欧元

也不能：

单独决定本国货币政策

也不能：

通过本币贬值快速恢复竞争力。

与此同时，当时欧元区没有完整的：

财政联盟
银行联盟
共同存款保险
统一危机处置机制

于是出现一个危险循环：

银行持有大量本国国债

政府又要在银行出问题时救银行

所以：

银行资产恶化
→ 政府救助成本↑
→ 主权信用恶化
→ 国债价格↓
→ 银行持有的国债进一步亏损
→ 银行更弱

这就是：

Sovereign-Bank Doom Loop

主权—银行死亡循环。

更麻烦的是：

市场如果开始相信某国可能退出欧元：

该国国债收益率↑

高利率本身又使政府债务更难持续。

于是市场预期可能具有一定自我实现性。

欧债危机因此不仅是：

“南欧政府花钱太多。”

一些国家确实有严重财政问题；

但欧元区制度设计不完整、银行体系脆弱、私人部门失衡、缺少共同危机管理机制同样重要。

ECB后来也明确承认危机暴露了货币联盟架构在财政规则、宏观失衡、金融监管以及危机管理方面的缺陷。

2012年Draghi对维护欧元的强力承诺，以及随后设计的OMT框架，极大降低了尾部解体风险。

这里第一次清楚展示：

Central Bank Backstop

央行最后支持的可信度，

本身就可以改变主权债券市场均衡。

八、为什么2010年代逐渐形成“低利率常态”？

危机结束以后，人们原本可能认为：

经济恢复
→ 利率回到1980—90年代水平

但实际并没有完全发生。

越来越多经济学家开始讨论：

r*

自然实际利率

长期下降。

为什么？

没有单一答案。

可能包括：

人口老龄化
→ 储蓄意愿提高

收入财富集中
→ 高收入群体储蓄率更高

全球安全资产需求
→ Treasury等资产收益率下降

投资品价格下降
→ 企业实现同样生产能力不需要过去那么多资本

危机后风险偏好下降
→ 安全资产需求上升

生产率与人口增长放缓
→ 企业投资需求下降

于是可能出现：

Desired Saving ↑
+
Desired Investment ↓

使均衡实际利率：

r*↓

Larry Summers重新提出：

Secular Stagnation

长期停滞

来描述一种可能状态：

私人需求长期不足，
需要非常低利率才能接近充分就业。

这个观点有争议，但它准确抓住了2010年代一个重大问题：

为什么经济已经扩张很多年，

利率却仍然很低？

九、2010年代真正形成了什么样的金融世界？

可以把这个时代压缩成一个循环：

2008资产负债表崩溃
→ 私人去杠杆
→ 需求弱
→ 通胀低
→ 央行长期低利率
→ QE压低长期收益率
→ 投资者Search for Yield
→ 债券/股票/房地产估值上升
→ 财富效应和融资改善
→ 经济缓慢恢复

但这个循环产生了新的政治经济问题。

第一，资产持有者获益更多。

如果股票和房地产上涨：

拥有大量资产的人

显然直接获益更多。

所以有人认为QE扩大财富不平等。

但需要公平地看反事实：

如果央行不稳定金融体系，出现更深衰退和失业，

低收入劳动者也可能受到巨大伤害。

所以更严谨的结论是：

QE存在分配效应；

净分配结果必须同时考虑：

资产价格渠道
和
避免失业/萧条的宏观效果。

第二，企业可能越来越依赖廉价资本。

低利率可以支持真正高回报投资，

也可能维持：

低效率企业
高杠杆公司
资产价格投机

这会引出所谓：

Zombie Firms

以及资本错配争论。

第三，央行越来越深地进入金融市场。

过去央行主要调整：

短期利率。

2008以后，它开始直接改变：

资产负债表规模
长期债券供给
MBS市场
Forward Guidance

现代货币政策由此从：

Price of Money

进一步进入：

Quantity and Composition of Central Bank Balance Sheet

这就是今天理解Fed必须具备的视角。

本课真正要留下的四个框架

1. QE不是简单“印钱发给居民”。

它首先是：

央行购买资产
→ 创造准备金
→ 改变私人部门资产组合和期限风险
→ 压低部分收益率/风险溢价
→ 放松金融条件

2. 银行贷款不是把准备金机械借出去。
